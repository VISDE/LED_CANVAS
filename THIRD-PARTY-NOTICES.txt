Led Canvas
----------

Led Canvas source, binaries, installer assets created for Led Canvas, and
project-owned documentation are proprietary/all-rights-reserved except where a
separate third-party license applies.

SimHub SDK and Runtime Assemblies
---------------------------------

The project references SimHub SDK/runtime assemblies from a local SimHub SDK
cache or installation. SimHub SDK DLLs and vendor binaries must not be committed
to this release repository. The current installer package script copies Led
Canvas plugin/UI binaries and selected Led Canvas assets, not SimHub SDK DLLs.

License/redistribution status: needs local confirmation before any SimHub SDK or
runtime assembly is bundled directly.

Newtonsoft.Json and log4net
---------------------------

The project references Newtonsoft.Json and log4net through the local SimHub
runtime/SDK path with Private=False. They are not directly copied by the current
installer package script.

If a future package redistributes either library directly, add the corresponding
license texts and notices to this file and to the release package.
