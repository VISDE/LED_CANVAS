# Led Canvas Releases

This public repository hosts Led Canvas release notes, public legal notices, and
GitHub Release assets for installer downloads.

The Led Canvas source repository is private. Do not copy proprietary source,
build output folders, installer payloads, or generated artifacts into this
repository.

## Downloads

Installer binaries are uploaded as GitHub Release assets only. They are not
committed to this repository.

For each release, verify:

- Release tag and version.
- Installer file name.
- File size.
- SHA256 hash.
- Current EULA and Privacy Notice links.

## About GitHub Source Archives

GitHub automatically shows `Source code (zip)` and `Source code (tar.gz)` links
on every release. In this repository those archives contain only the public
documents committed here, such as README files, release notes, checklists, and
legal notices. They do not contain the private Led Canvas source code, and they
do not include uploaded installer assets unless a binary is mistakenly committed
to this repository.
